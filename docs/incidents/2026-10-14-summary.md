# Incident Summary — 2026-10-14

| | |
|---|---|
| ประเภท | การตั้งค่าสิทธิ์เข้าถึงฐานข้อมูล production ไม่ครบ |
| พบโดย | การตรวจระบบตามแผน redesign (Step 00–06) |
| ความรุนแรง | Critical |

## สรุป
ระหว่างตรวจ production พบว่าตารางข้อมูลหลักยังไม่ได้จำกัดสิทธิ์ให้เฉพาะผู้ใช้ที่ login แล้ว เจ้าของระบบปรับการตั้งค่าสิทธิ์ทันที และตรวจยืนยันจากภายนอกแล้วว่าผู้ที่ไม่ได้ login เข้าถึงข้อมูลไม่ได้

## งานต่อเนื่อง
- ตรวจ log ย้อนหลังว่ามีการเข้าถึงที่ผิดปกติก่อนแก้หรือไม่
- ยืนยันรายชื่อบัญชีผู้ใช้ทั้งหมด
- ทำการควบคุมสิทธิ์ฉบับถาวรผ่าน migration ที่ตรวจสอบได้ (allowlist สมาชิก, RLS tests ใน CI) ตาม `docs/redesign/database-migration-plan.md` (M000–M002)

บันทึกรายละเอียดทางเทคนิคเก็บแยกไว้นอก repository สาธารณะ
