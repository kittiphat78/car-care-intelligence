## สิ่งที่เกิดขึ้น

ถ้ากดเข้าสู่ระบบก่อนหน้า login โหลดเสร็จ (เครื่องช้าหรือเน็ตช้า แล้วกด Enter หรือแตะปุ่มเร็ว) เบราว์เซอร์จะส่งฟอร์มแบบ GET ทำให้อีเมลและรหัสผ่านไปอยู่ใน URL ของหน้า `/login` [V จากการทดลองบน staging]

URL นั้นอาจถูกเก็บไว้ที่:
- **Vercel request logs** ของ production [I]
- **ประวัติของเบราว์เซอร์** บนเครื่องที่กด [I]
- ไม่ถูกส่งไปเว็บอื่น เพราะ `Referrer-Policy: origin-when-cross-origin` ส่งแค่ชื่อเว็บไปยังโดเมนอื่น [V header]

ไม่ทราบว่ามีใครเจอเหตุการณ์นี้จริงหรือไม่ [U]

## สาเหตุ

O-01 ใน Step 09 ทำให้ฟอร์ม login มาพร้อม HTML ตั้งแต่แรก (เพื่อให้เร็วขึ้น) แต่ฟอร์มไม่มี `method="post"` และไม่ได้ปิดปุ่มไว้ระหว่างรอ JavaScript · test ใน CI ใช้ Chromium ที่เร็วพอจึงไม่เห็น

## งานที่ยังค้าง (เจ้าของ)

1. Vercel → Logs ค้น `password=` ในช่วง 05:05–20:12
   - แผน Hobby เก็บ log สั้น จึงอาจไม่เหลือแล้ว [U]
   - **ถ้าไม่พบ log ของช่วงนั้นเลย ไม่ได้แปลว่าปลอดภัย**
2. ถ้าพบ หรือตรวจไม่ได้ ให้เปลี่ยนรหัสผ่านของบัญชีที่ login ในช่วงนั้น เป็นทางที่ปลอดภัยและใช้เวลาไม่นาน
3. ลบประวัติเบราว์เซอร์ที่มี `/login?email=` บนเครื่องในร้านที่ใช้ช่วงนั้น
