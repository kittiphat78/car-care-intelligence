## 3. Navigation Hierarchy

```
ระดับ 0  /login                          (ก่อนเข้าระบบ)
ระดับ 1  ภาพรวม  ค้างชำระ  [บันทึก]  ประวัติ  เพิ่มเติม     ← primary nav (ทุกหน้าหลังเข้าระบบ)
ระดับ 2  ├─ ภาพรวม: รายการวันนี้ ─► แก้ไขรายการ (dialog)
         ├─ ค้างชำระ: กลุ่มลูกค้า ─► สร้างบิล (download) │ เคลียร์ยอด (dialog ยืนยัน) │ แก้ไขรายการ (dialog)
         ├─ บันทึก: แท็บรายรับ │ รายจ่าย
         ├─ ประวัติ: แท็บรายรับ │ รายจ่าย ─► แก้ไขรายการ (dialog) │ Export (dialog)
         └─ เพิ่มเติม: theme │ ออกจากระบบ (dialog ยืนยัน)
```

- ความลึกสูงสุด 2 ระดับ และทุก dialog ปิดได้ด้วย back, Escape หรือปุ่มปิด
- ไม่มีเมนูซ้อนหรือ hamburger บนมือถือ

### 3.1 Primary nav ตามขนาดจอ

| Breakpoint | ความกว้าง | อุปกรณ์ตัวแทน | Nav | เนื้อหา |
|---|---|---|---|---|
| Compact | < 600px | มือถือ | Bottom bar 5 ช่อง, บันทึกตรงกลาง | 1 คอลัมน์ เต็มความกว้าง |
| Medium | 600–1023px | tablet แนวตั้ง | Bottom bar 5 ช่อง | 1 คอลัมน์ (กว้างสูงสุด ~720px) และบางส่วนเป็น 2 คอลัมน์ (สถิติ, ฟอร์ม) |
| Expanded | ≥ 1024px | tablet แนวนอน, PC | Sidebar ซ้าย (ไอคอน + ข้อความ) และปุ่ม "บันทึก" เด่นด้านบน | 2 คอลัมน์ (กว้างสูงสุด ~1200px) |

- Badge บน "ค้างชำระ" แสดง **จำนวนลูกค้า** ที่ค้าง (ไม่ใช่ยอดเงิน เพื่อไม่ให้ nav รก) ไม่แสดงเมื่อเป็น 0 และมีข้อความสำหรับ screen reader ด้วย ("ค้างชำระ 3 ราย")
- หน้า `/login` และหน้า error ไม่มี nav

## 4. โครงสร้างเนื้อหาแต่ละหน้า (Content Priority)

ลำดับในตารางคือลำดับบนมือถือ (บนลงล่าง) และคอลัมน์ "Expanded" ระบุตำแหน่งบนจอใหญ่
