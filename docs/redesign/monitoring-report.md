## 3. เกณฑ์ตัดสิน

| เห็นอะไร | ทำอะไร |
|---|---|
| login ไม่ได้ · บันทึก/แก้/ลบไม่ได้ · ยอดภาพรวมหรือค้างชำระผิด · หน้าใดขึ้น error ทุกครั้ง · มีคนเห็นข้อมูลที่ไม่ควรเห็น | **Rollback ทันที** (Vercel → Deployments → `4162c44` → Instant Rollback) แล้วเปิด incident |
| 5xx ซ้ำ · รายงาน error `code` เดียวกัน ≥ 3 ครั้งใน 1 ชม. หรือจาก ≥ 2 เครื่อง | ตรวจสาเหตุภายในวันนั้น · ถ้าเกี่ยวกับของใหม่ (การ์ดค้างชำระ, อากาศ, กราฟ) → rollback |
| error ครั้งเดียว · ข้อความ known (`interactive-widget`, เน็ตหลุด, `ChunkLoadError` ที่กราฟแสดงกล่อง "โหลดกราฟไม่สำเร็จ") | จดไว้ เฝ้าดูต่อ |

Rollback ย้อนได้แค่โค้ด: ข้อมูลที่บันทึก/แก้/ลบระหว่างนั้นยังอยู่ตามเดิม (release นี้ไม่มี schema ใหม่ ข้อมูลจึงใช้กับ `4162c44` ได้ [I])
