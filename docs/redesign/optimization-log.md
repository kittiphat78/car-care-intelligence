## 3. ข้อควรรู้เรื่องตัวเลข

- Lighthouse mobile ใช้ **simulated throttling**: วัดจริงแบบไม่จำกัดความเร็ว แล้วจำลองว่าบนมือถือช้า + 4G ช้าจะใช้เวลาเท่าไร ตัวเลข LCP/TBT จึงเป็นค่าประมาณ ส่วน "observed" คือเวลาที่เกิดจริงในการวัด
- LCP แบบจำลองของ `/` และ `/more` สูงขึ้น ขณะที่การวัดในเบราว์เซอร์จริงและค่า observed ของ Lighthouse ไม่ช้าลง → ใช้การวัดจริงตัดสิน (`performance-audit.md` §3, §5)
- ทุกรอบที่ใช้ตัดสินรันโดยไม่มีงานอื่นแย่ง CPU และเสียบสายชาร์จ · รอบที่มี test อื่นรันซ้อน (ผลแย่ลง 10–30 คะแนน) และรอบที่ใช้แบตเตอรี่ (TBT สูงขึ้น 3–5 เท่าแม้หน้าที่ไม่ได้แก้) ถูกทิ้ง · ตัวเลขชุดแรก ๆ ในประวัติของงานนี้ใช้หาปัญหาเท่านั้น
