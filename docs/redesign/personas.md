## 2. Personas

| ด้าน | รายละเอียด | หลักฐาน |

| เป้าหมาย | รู้ว่าวันนี้ได้เงินสดเท่าไร, ทวงหนี้เต็นท์ให้ครบ และส่งรายงานให้ธนาคาร | G2, G3, G4 [V] |

| ข้อจำกัด | สายตาอาจไม่ดี จึงต้องการตัวใหญ่ ซูมได้ และไม่อยากพิมพ์มาก | README "ลดการพิมพ์" [V], วัยผู้ใหญ่ [V] และสายตา [A] |

### P2 — "คนบันทึกหน้าร้าน" (REC)

| ด้าน | รายละเอียด | หลักฐาน |
|---|---|---|
| ใคร | พนักงานหรือสมาชิกครอบครัวที่ล้างหรือขัดรถและบันทึกงาน | มีหลายบัญชี [V] ส่วนบทบาท [I] |

## 3. สิ่งที่ไม่รู้และส่งผลต่อการออกแบบ

| # | Unknown | ผลถ้าเดาผิด | ค่าออกแบบที่ใช้ระหว่างนี้ |
|---|---|---|---|
| PU-1 | งานไหนทำบนอุปกรณ์ไหน (เช่น บันทึกบน tablet และดูยอดบนมือถือ) | layout หลักอาจไม่เหมาะกับอุปกรณ์ที่ใช้มาก | ออกแบบทุก route ให้ใช้ได้ครบทั้ง 3 ขนาด (D-12) |
