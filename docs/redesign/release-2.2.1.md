# v2.2.1 — กดแล้วตอบสนองทันที + ปุ่ม "เพิ่มเบอร์"

> สถานะ: **พร้อม release** (รอเจ้าของ merge) · RC `v2.2.1-rc.4` (`b402810`, tag แล้ว) · ฐาน: `v2.2.0` (`18b52bc`)
> SemVer: PATCH (ปรับความเร็วหน้าจอ + ปุ่มลัดในหน้าลูกค้า + อัปเดต dependency ด้านความปลอดภัย · ไม่มี migration · ไม่เปลี่ยนข้อมูล) · ป้าย: **[V]** Verified · **[I]** Inferred · **[U]** Unknown

## สำหรับคนในร้าน

- **กดเมนูแล้วรู้ทันทีว่ากดติด:** แท็บที่กดขึ้นสีและกะพริบระหว่างเปิด หน้าใหม่ขึ้นเป็นกรอบเทาก่อนแล้วข้อมูลตามมา · กลับไปแท็บที่เปิดไปแล้วใน 5 นาที หน้าขึ้นทันทีพร้อมตัวเลขชุดล่าสุด แล้วอัปเดตตามเอง (ปุ่ม ⟳ ในหน้าแรกหมุนระหว่างอัปเดต)
- **เปิด dialog ทันที:** เคลียร์ยอด, แก้ไขรายการ, ส่งออก Excel, ออกจากระบบ · สลับแท็บรายรับ/รายจ่าย ตัวกรองประวัติ และการเรียงในหน้าค้างชำระก็เปลี่ยนทันที
- **หน้าประวัติ:** แท็บและตัวกรองเปลี่ยนก่อน รายการตามมา (จางลงและกดไม่ได้สั้น ๆ ระหว่างรอ)
- **หน้าลูกค้าที่ยังไม่มีเบอร์** มีปุ่ม "เพิ่มเบอร์" ข้างข้อความ "ยังไม่มีเบอร์" เปิดฟอร์มแก้ไขที่ช่องเบอร์ให้เลย
