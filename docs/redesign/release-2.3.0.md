## สำหรับคนในร้าน

- **หน้าตาใหม่ทั้งแอป:** การ์ดกระจกบนพื้นแสงไล่สีฟ้า-ม่วง · ปุ่มหลักสีน้ำเงิน · ตัวหนังสือ Noto Sans Thai อ่านง่ายขึ้นและโหลดเร็วกว่าเดิม · ปุ่ม เมนู ข้อความ และลำดับการทำงานเหมือนเดิมทุกหน้า
- **หน้าแรก:** ป้าย ออนไลน์ · ลูกค้าเดือนนี้ · ค้างชำระกี่ราย · การ์ดรายรับ วันนี้ / สัปดาห์นี้ (ตั้งแต่วันจันทร์) / เดือนนี้ · ทางลัด 4 ปุ่ม · งานวันนี้ (สัดส่วนล้าง/ขัด, รับเงินแล้ว/ค้าง) · กราฟเส้น 7/30 วัน
- **เพิ่มรายการ:** ตัวเลือกล้างรถ/ขัดสีมีไอคอนในกรอบสี (หน้าเพิ่มและหน้าแก้ไข)
- **ประวัติ / ลูกค้า / ค้างชำระ / ตั้งค่า:** หัววันที่ทึบอ่านง่าย · การ์ดลูกค้าและการ์ดค้างชำระมีไอคอน · หัวการ์ดตั้งค่ามีไอคอน
- **หน้าเข้าสู่ระบบ:** ชื่อร้านตัวใหญ่ ป้ายบอกว่าเน็ตต่ออยู่ไหม จอคอมแบ่ง 2 ฝั่ง
- **แอปที่ติดตั้งบนมือถือ:** สีแถบบนเปลี่ยนเป็นสีพื้นใหม่เองเมื่อมือถือดึงข้อมูลแอปใหม่ ไม่ต้องติดตั้งใหม่
