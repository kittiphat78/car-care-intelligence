# v2.4.0 — แอปเร็วขึ้น (งานความเร็ว 3a–3e)

> สถานะ: **Release candidate** · RC `v2.4.0-rc.2` (`e6d4f85`) · ฐาน: `v2.3.0` (`abd062b`)
> SemVer: MINOR (หน้าตา เมนู ปุ่ม ข้อความ flow URL และฟอนต์เหมือน v2.3.0 · เพิ่มป้าย "กำลังส่ง / ยังไม่ส่ง" ที่เจ้าของเลือก · ไม่มี migration · ไม่เปลี่ยนข้อมูล) · ป้าย: **[V]** Verified · **[I]** Inferred · **[U]** Unknown

## สำหรับคนในร้าน

- **เปิดแอปเร็วขึ้นมาก:** เปิดหน้าใหม่ (เปิดแอป รีเฟรช กดลิงก์) ข้อมูลขึ้นในราว 1.2–1.6 วินาที จากเดิม 5–6.5 วินาทีบนมือถือเน็ตช้า · เปลี่ยนแท็บครั้งแรกเหลือราว 0.75 วินาที จากเดิม 2–3 วินาที
- **บันทึกขึ้นทันที:** กด "บันทึก" แล้วกลับหน้าแรกทันที รถคันใหม่อยู่บนสุดพร้อมป้าย **"กำลังส่ง"** ซึ่งหายไปเองเมื่อส่งเสร็จ (ส่วนใหญ่ไม่ถึง 1 วินาที) · แก้ราคา ลบ และเคลียร์ยอดก็ขึ้นทันที (กล่องยืนยันตอนลบและเคลียร์ยอดยังอยู่เหมือนเดิม)
- **เน็ตหลุดตอนบันทึก:** รถคันนั้นยังอยู่พร้อมป้าย **"ยังไม่ส่ง"** แอปส่งให้เองเมื่อเน็ตกลับมา หรือแตะ "ส่งอีกครั้ง" · ส่งซ้ำแล้วไม่เกิดแถวซ้ำ · ระหว่างที่ยังส่งไม่หมด ถ้าจะปิดแอป เบราว์เซอร์จะถามก่อน (ถ้าปิดไปตอนนั้นรายการที่ยังไม่ส่งจะหาย)
- **แก้ ลบ เคลียร์ยอด ไม่สำเร็จ:** หน้าจอกลับเป็นเหมือนเดิม พร้อมปุ่ม "แก้อีกครั้ง" หรือ "ลองอีกครั้ง"
- ปุ่มบันทึกไม่หมุน "กำลังบันทึก…" แล้ว เพราะไม่ต้องรอ

## Deploy และตรวจหลังขึ้น production

ทำหลังเจ้าของ merge release PR · ตรวจแบบอ่านอย่างเดียว:
- GitHub deployment ของ merge commit = Production + success · หน้า `/login` แสดง `v2.4.0`
- `x-vercel-id` ของ production ลงท้าย `::sin1` (function ย้ายจาก `iad1` เป็นครั้งแรกบน production)
- header ความปลอดภัยครบ · JavaScript ชี้ Supabase production เท่านั้น

เจ้าของลองบนมือถือด้วยบัญชีร้าน (ADR-19): บันทึกรถ 1 คันแล้วเห็น "กำลังส่ง" หายไป · แก้ราคา 1 รายการ · เปิดทุกแท็บ · (ถ้าสะดวก) ปิดเน็ตตอนกดบันทึกแล้วเห็น "ยังไม่ส่ง" และส่งเองเมื่อเปิดเน็ต

## Known issues

- รายการที่ยังไม่ส่งอยู่ในหน่วยความจำของแท็บเท่านั้น (ADR-26): ปิดแอปหรือออกจากระบบตอนนั้นจะหาย (เบราว์เซอร์ถามก่อนปิด)

- Lighthouse จำลองบน Preview: `/debts` LCP บางรอบสูงกว่า 3d เพราะชิ้นที่นับเป็น LCP เปลี่ยนจากหัวข้อหน้าเป็นการ์ดข้อมูล · วัดในเบราว์เซอร์จริงข้อมูลขึ้นเร็วกว่า
- หน้าตาใหม่ทั้งแอป (3 แนวทางจาก prototype) พักไว้ ยังไม่ได้เลือก
