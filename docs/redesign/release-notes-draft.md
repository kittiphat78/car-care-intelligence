## สำหรับคนในร้าน (ภาษาง่าย)

- **ออกจากระบบเฉพาะเครื่องที่กด** เครื่องอื่นที่ใช้บัญชีเดียวกัน (เช่น tablet หน้าร้าน) ยังใช้ต่อได้ · เน็ตหลุดตอนกดก็ยังออกจากเครื่องนี้ได้
- **กด Enter ในช่องกรอก = ไปช่องถัดไป** ไม่บันทึกเองโดยไม่ตั้งใจแล้ว (ปุ่ม "ไป" บนคีย์บอร์ดมือถือก็เช่นกัน)
- **หน้าภาพรวมไม่กระโดดแล้ว** ตอนข้อมูลโหลดเสร็จ การ์ดไม่เลื่อนลงทั้งหน้า (เดิมเกือบทุกครั้งบนมือถือ)
- **บันทึกไม่สำเร็จจะเห็นข้อความทันที** หน้าจะเลื่อนขึ้นไปที่ข้อความ (เดิมข้อความอยู่นอกจอ)
- **หน้า login ขึ้นเร็วขึ้น** (ราว 2.9 → 1.1 วินาทีบนมือถือช้า) และไม่กระตุก
- **หน้าประวัติลื่นขึ้น** · มือถือจอแคบมาก (320px) ปุ่มบันทึกไม่ล้นจอ
- ผู้ที่ใช้ screen reader หรือสั่งด้วยเสียง เรียกปุ่มตามคำที่เห็นบนจอได้

## การเปลี่ยนแปลง

### Changed
- ออกจากระบบใช้ `scope: 'local'` (ออกเฉพาะเครื่องนี้) และหน้ายืนยันบอกว่าเครื่องอื่นยังใช้ได้ (D-03, PR #43)
- Enter ใน `<input>` ของฟอร์มบันทึกย้ายไปช่องถัดไป (D-01, PR #42)
- หน้าภาพรวมบนมือถือ: ปุ่มอากาศ/อัปเดตอยู่บรรทัดของตัวเอง · skeleton ทุกการ์ดสูงเท่าของจริง (O-08–O-10, PR #46)

### Fixed
- ออกจากระบบตอนเน็ตหลุดแล้วเครื่องยังไม่ออก (D-06, PR #43)
- บันทึกไม่สำเร็จแล้วข้อความอยู่นอกจอบนมือถือ (U-01, PR #46)
- CLS หน้าภาพรวม 0.545 → 0.002 · หน้า login 0.141 → 0 (PR #46)
- ปุ่มบันทึกล้นจอที่ 320px (A-02, WCAG 1.4.10) · ชื่อปุ่ม 75 ปุ่มไม่ตรงกับข้อความบนจอ (A-01, WCAG 2.5.3) (PR #46)
- ข้อมูลทดสอบ `ci_fixtures.sql` ทำให้ Supabase Auth ค้นหา user ไม่ได้ (D-02, เฉพาะฐานข้อมูลทดสอบ, PR #42)

### Performance
- ฟอร์ม login มาพร้อม HTML (เลิก `useSearchParams` ใต้ Suspense ว่าง) (O-01)
- ประวัติวาดเฉพาะ list (มือถือ) หรือตาราง (PC) อย่างเดียว · TBT ลดครึ่งหนึ่ง (O-04)
- ตัวจัดรูปแบบวันที่ใช้ซ้ำ (เร็วขึ้น ~9 เท่าต่อครั้ง) (O-03) · กราฟโหลดหลังข้อมูล (O-07) · zod/mini (O-06)

### Security
- ฟอร์ม login ไม่ส่งเองก่อนหน้าพร้อม (เดิมเบราว์เซอร์ส่งแบบ GET ทำให้รหัสผ่านอยู่ใน URL) · ฟอร์มบันทึกได้การป้องกันเดียวกัน (D-07, hotfix `7903755`)
- ตัด `'unsafe-eval'` ออกจาก CSP ของ production (D-05, PR #44)
- อัปเกรด dependency ที่มีช่องโหว่ (เวอร์ชันที่ออกมาแล้ว ≥ 2 สัปดาห์): production High 4 → 0 · dev Critical 2 → 0 (D-04, PR #45)
- CI: ตรวจว่า bundle ที่ส่งให้เบราว์เซอร์ไม่มี key ฝั่ง server (PR #42)

### Tests / Dev
- E2E: ความปลอดภัย/RLS 3 บัญชี, regression ฟีเจอร์เดิม, UI quality, ออกจากระบบ 2 เครื่อง, CSP violation · WCAG 2.2 + Label in Name + ความกว้าง 320px ทุก PR (E2E 49 test, unit 400 test)
