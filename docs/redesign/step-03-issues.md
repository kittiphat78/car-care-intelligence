- **ความเสี่ยงถ้าปล่อยไว้:** เป้า "ไม่ช้ากว่า baseline" (AC-04-3, SM-07) ไม่มีค่าอ้างอิง และ IA ใหม่ยังไม่ผ่านการทดสอบกับผู้ใช้จริง

## S03-04 — ส่งต่อให้ Step 05 ออกแบบเชิงเทคนิค · Medium · `UNRESOLVED`

- **รายการ:**
  1. **บันทึกที่ไม่รู้ผล** (timeout หลังส่ง) ต้องไม่สร้างรายการซ้ำเมื่อกดลองใหม่ (UF-REC-01) เช่น ใช้ idempotency key หรือ client-generated id
  2. **Edit conflict** จาก 2 เครื่อง (UF-EDIT-01) ซึ่ง MVP ใช้ last-write-wins และเสนอให้ตรวจ `updated_at`
  3. **การส่งเฉพาะ field ที่เปลี่ยน** ใน edit (กัน ER-01 ชั้นที่สอง)
  4. **รับชำระครบต้องคืนจำนวนแถวที่ update** เพื่อเทียบกับที่ยืนยัน (UF-DEBT-02)
  5. **Session refresh และ draft storage** แยกตามบัญชี (UF-AUTH-03, UF-REC-05)
- **สาเหตุ:** เป็นการตัดสินใจด้าน architecture และ data ซึ่งอยู่นอกขอบเขต Step 03
- **ความเสี่ยงถ้าปล่อยไว้:** flow ใน `user-flows.md` implement ไม่ได้ครบ
- **Prompt สำหรับแก้ภายหลัง:** รวมอยู่ใน Prompt ของ Step 05 ("ให้ครอบคลุม S03-04 ข้อ 1–5")
