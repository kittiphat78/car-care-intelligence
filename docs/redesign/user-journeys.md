## CUJ-2 — บันทึกรายรับล้างรถ (ชำระแล้ว) แล้วกลับดูยอด

| | |
|---|---|
| Persona | REC |
| Trigger | ล้างรถเสร็จและลูกค้าจ่ายเงินสด |
| อุปกรณ์ | Tablet หรือมือถือ |
| บริบท | อาจมีรถรอคิว และมืออาจเปียก [A] |

| ขั้น | ปัจจุบัน (แตะ) | เป้าหมาย (แตะ) | หมายเหตุ |
|---|---|---|---|
| 1 ไปหน้าบันทึก | แตะ (+) = 1 | 1 | คงเดิม |
| 2 ประเภทงาน | ค่าเริ่มต้น "ล้างรถ" = 0 | 0 | |
| 3 ทะเบียน | แตะช่อง + พิมพ์ = 1 | 1 | ลูกค้าประจำแสดงอัตโนมัติ |
| 4 ราคา | แตะช่อง + พิมพ์ = 1 | 1 | |
| 5 ประเภทรถ | แตะ = 1 (อยู่ใต้ราคา) | 1 (อยู่ก่อนราคา) | PP-08 |
| 6 สถานะ | ค่าเริ่มต้น "ชำระแล้ว" = 0 | 0 | |
| 7 กดบันทึก | **เลื่อนลง** + แตะ = 1+scroll | 1 (แถบปุ่มติดจอ) | PP-07 |
| 8 ยืนยันผล | กลับ `/` (ไม่มีข้อความสำเร็จ) | กลับ `/` + toast "บันทึก กข 1234 ฿150 แล้ว" + รายการใหม่ไฮไลต์ | ผู้ใช้รู้แน่ว่าบันทึกสำเร็จ |
| **รวม** | **5 แตะ + เลื่อน + พิมพ์ 2 ช่อง** | **5 แตะ + พิมพ์ 2 ช่อง** | AC-04-3: ต้องไม่มากกว่า baseline |

**จุดเสี่ยง:** เน็ตหลุดขณะบันทึก → ข้อมูลในฟอร์มต้องไม่หาย (UF-REC-04) และกดซ้ำต้องไม่เกิดรายการซ้ำ (AC-06-1)

## CUJ-3 — บันทึกค้างชำระของเต็นท์ → ทวง → ออกบิล → เคลียร์ยอด

| | |
|---|---|
| Persona | REC (บันทึก) → OWN (ทวงและรับเงิน) |
| Trigger | เต็นท์ส่งรถมาขัดสีแบบเครดิต ต่อมาเต็นท์มาจ่ายรวม |
| ระยะเวลา | หลายวันถึงหลายสัปดาห์ |

| ช่วง | ขั้น | ปัจจุบัน | เป้าหมาย | แก้ |
|---|---|---|---|---|
| บันทึก | เลือก "ขัดสี" → ทะเบียน → ประเภทรถ → ราคา → **ค้างชำระ** → ชื่อเต็นท์ | ต้องกด "เพิ่มชื่อลูกค้า" ก่อนจึงเห็นช่องชื่อ และไม่ใส่ชื่อก็บันทึกได้ | เลือกค้างชำระแล้วช่องชื่อเปิดทันที พร้อม quick-pick และถ้าไม่ใส่ชื่อจะมี **คำเตือนแบบไม่บล็อก** | PP-09 |
| ติดตาม | เห็นยอดค้างบน `/` | การ์ดแจ้งเตือนสีแดงกะพริบ (`pulse-urgent`) | การ์ดค้างชำระ + badge จำนวนลูกค้าบน nav | PP-06 |
| ทวง | เปิดสมุดทวงหนี้ | modal (back ปิดไม่ได้) | หน้า `/debts` และเรียงตามยอดหรือความนาน | UXD-02 |
| ออกบิล | สร้างบิล → PDF ดาวน์โหลด | มีอยู่แล้ว | เหมือนเดิม + toast ยืนยันชื่อไฟล์ และเลขบิลไม่ซ้ำ (ขึ้นกับ Q-05) | ER-34 |
| รับเงิน | เคลียร์ยอด | `window.confirm` ไม่บอกจำนวน, ไม่ครอบคลุมชื่อว่าง/NULL | Dialog แสดง "เคลียร์ยอด: เต็นท์ A · 6 คัน · ฿8,400" และครอบคลุมทุกรายการในกลุ่ม | ER-03, PP-15 |
| ยืนยันผล | — | กลุ่มหายทันที (optimistic) | กลุ่มหาย + toast "เคลียร์ยอด เต็นท์ A ฿8,400 แล้ว" + ยอดบน `/` ลดลง | |

**จ่ายไม่ครบ:** ไม่มีการเคลียร์บางรายการ (D-14) ผู้ใช้ต้องแตะรายการในการ์ดเพื่อแก้สถานะทีละรายการ (UXD-03 ช่วยให้ทำได้จากหน้า `/debts` เลย)
