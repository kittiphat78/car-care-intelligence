# User Stories — Step 02

> วันที่: 2026-10-14 · Personas จาก `product-requirements.md` §3.1
> รูปแบบ: **ในฐานะ** … **ฉันต้องการ** … **เพื่อ** … · ทุก story มี acceptance criteria ใน `acceptance-criteria.md` (AC-<US>-<n>)

## Epic E1 — เข้าใช้งานอย่างปลอดภัย

| ID | Story | Pri | FR |
